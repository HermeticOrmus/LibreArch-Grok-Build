# librearch-core (Grok plugin stub)

Bundles core LibreArch skills for install-from-path.

Skills live under repo `skills/` (canonical) and `.grok/skills/` (dogfood copy). Copy or symlink into this plugin's `skills/` when packaging. First-run install does not require this plugin — see [QUICK_START.md](../../../QUICK_START.md).

Melted in this pack: `adr-write`, `blast-radius-lite`, `hexagonal-ports`. The rest remain stubs. Honest table: [docs/DEPTH_MATRIX.md](../../../docs/DEPTH_MATRIX.md).
